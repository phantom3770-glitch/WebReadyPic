# WebReadyPic

Инновационное Single Page Application (SPA) для пакетной подготовки, оптимизации и сжатия изображений для веб-ресурсов и e-commerce.

Приложение работает полностью локально в браузере (клиентская часть), гарантируя конфиденциальность ваших данных: ни один файл не покидает ваше устройство.

## ✨ Основные возможности

*   **Локальное сжатие и конвертация:**
    *   Поддержка форматов **WebP, JPEG, PNG**.
    *   4 пресета качества: *Лёгкое*, *Оптимальное*, *Сильное*, *Экстремальное*.
    *   Автоматический ресайз по длинной стороне.
*   **Оптимизация под e-commerce (Карточка товара):**
    *   Приведение изображений к единому соотношению сторон (**1:1, 3:4, 4:3**).
    *   Инновационный алгоритм центрирования (*Letterbox*) с 10% безопасными отступами.
    *   Выбор подложки фона (прозрачный, чистый белый, студийный серый, элегантное дерево).
    *   Добавление мягкой реалистичной тени под объектом.
*   **Пакетный режим:**
    *   Загрузка до 50 файлов за одну сессию с автоматической валидацией лимита.
    *   Очередь обработки с визуальным прогрессом (shimmer-эффект, статус готовности).
    *   Сравнение размеров (исходный → сжатый) и отображение процента экономии места.
    *   Экспорт обработанных файлов в один клик в виде **ZIP-архива** (с помощью JSZip).
*   **Современный Premium UI/UX:**
    *   Темная тема с неоновыми акцентами и эффектом стекломорфизма (glassmorphism).
    *   Фиксированная боковая панель настроек слева/справа.
    *   Полноценная поддержка Drag-and-Drop.
    *   Интернационализация (i18n): быстрое переключение интерфейса между **RU** и **EN**.

## 🛠️ Технологический стек

*   Чистый HTML5 и семантическая верстка.
*   **CSS (Tailwind CSS CDN)** для адаптивного стильного дизайна.
*   **Ванильный JavaScript (ES2020+)** с использованием Canvas API для рендеринга и обработки изображений.
*   **JSZip** для динамической генерации архивов на стороне клиента.

## 🚀 Как запустить

Поскольку проект представляет собой SPA в одном файле, установка дополнительных зависимостей не требуется:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ПРОФИЛЬ/WebReadyPic.git
   ```
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Safari, Edge).

*Для корректной работы всех функций (включая загрузку шрифтов и библиотек с CDN) требуется подключение к интернету.*
